# Mini Banking & Money Transfer System

A Spring Boot backend application for secure bank account management and transactional money transfers.

## Features
* **Account Management:** Create accounts, check balances, and view transaction history.
* **Security:** Secure login and role-based access control using Spring Security & JWT.
* **Safe Transfers:** Transactional balance updates ensuring data consistency during money transfers.
* **Fault Tolerance:** Built-in resilience with Resilience4j (Circuit Breaker & Retry).

## Tech Stack
* **Language:** Java 21
* **Frameworks:** Spring Boot, Spring Security, Spring Data JPA
* **Database:** MySQL
* **Tools:** Hibernate, JWT, Resilience4j, Maven
